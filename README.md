# Nexus Backend Tasks

A curated collection of backend development projects, task solutions, and mini-applications built during the Nexus program. This repository tracks practical implementations ranging from system logic to API design.

## Repository Structure

```text
Nexus-Backend-Tasks/
├── 01-sequencing-animation/           # Animation sequencing & custom search/filter logic
├── ecommerce-backend/                 # REST API handling core e-commerce functionalities
├── product-inventory-api/             # RESTful product inventory API built with Node.js & Express
├── student-management-api/            # Student management API implementation
├── student-management-api-with-auth/  # Student management API with authentication features
└── task-management-system/            # Full-featured backend system for task management

```

## Projects Included

* **01-sequencing-animation**: JavaScript-based sequencing logic and filtering mechanisms.
* **ecommerce-backend**: Backend REST API designed for products, users, carts, and orders using Node.js, Express, and MongoDB.
* **product-inventory-api**: RESTful API designed to manage product catalogs and inventories efficiently using Node.js and Express.
* **student-management-api**: Backend system for managing student data and records.
* **student-management-api-with-auth**: Student management API upgraded with user authentication and security features.
* **task-management-system**: Comprehensive backend application built for creating, organizing, and tracking tasks.
